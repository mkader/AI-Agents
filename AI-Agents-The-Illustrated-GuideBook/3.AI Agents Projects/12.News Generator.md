* The app takes a user query, searches the web for it, and turns it into a well-crafted news article, with citations. 
* Tech stack: 
  * Cohere ultra-fast Command R 7B as LLM 
  * CrewAI for multi-agent orchestration 
* Workflow:  
  * We’ll have two agents in this multi-agent app: 
    * Research analyst agent: 
      * Accepts a user query. 
    * Uses the Serper web search tool to fetch results from the internet. 
    * Consolidates the results. 
      * Content writer agent: 
    * Uses the curated results to prepare a polished, publication-ready article.

```mermaid
sequenceDiagram
    actor User
    participant UI as Streamlit UI
    participant App as app.py
    participant Generate as generate_content(topic)
    participant Crew as CrewAI Crew
    participant Analyst as Senior Research Analyst
    participant Search as SerperDevTool
    participant Writer as Content Writer
    participant LLM as Azure OpenAI deployment

    App->>UI: Render page, topic field, temperature slider, and Generate button
    User->>UI: Enter topic and select temperature
    User->>UI: Click Generate Content
    UI->>App: Rerun with generate_button = true
    App->>UI: Show "Generating content..." spinner
    App->>Generate: generate_content(topic)

    Note over Generate: Creates an unused command-r LLM instance.<br/>The slider value is not passed here.
    Generate->>Generate: Create Azure OpenAI LLM from environment variables<br/>(temperature is hard-coded to 0.7)
    Generate->>Search: Create SerperDevTool (10 results)
    Generate->>Generate: Configure research and writing agents,<br/>tasks, and Crew
    Generate->>Crew: kickoff(inputs={"topic": topic})

    Crew->>Analyst: Execute research task
    Analyst->>LLM: Generate search queries / analyze findings
    LLM-->>Analyst: Tool-use or analysis response
    Analyst->>Search: Search the web
    Search-->>Analyst: Search results and source URLs
    Analyst->>LLM: Synthesize verified research brief
    LLM-->>Analyst: Research brief with citations
    Analyst-->>Crew: Return research task output

    Crew->>Writer: Execute writing task with research brief
    Writer->>LLM: Generate cited markdown article
    LLM-->>Writer: Article
    Writer-->>Crew: Return writing task output
    Crew-->>Generate: Crew output
    Generate-->>App: Return result

    App->>UI: Display Generated Content and result
    App->>UI: Offer download using result.raw as a markdown file
    User->>UI: Optionally download article

    alt Generation raises an exception
        Generate-->>App: Propagate exception
        App->>UI: Display error message
    end
```
