* Build a multi agent brand monitoring app that scraps web mentions and produces insights about a company. 
* Tech stack: 
  * Bright Data to scrape data at scale 
  * CrewAI for orchestration 
  * Ollama to serve DeepSeek locally 
* Workflow: 
  * Use Bright Data to scrape brand mentions across X, Instagram, YouTube, websites, etc. 
  * Invoke platform-specific Crews to analyze the data and generate insights. 
  * Merge all insights to get the final report.

* **Concurrency note:** The five branches are scheduled as async tasks,  but `scrape_urls()` uses synchronous HTTP requests and `time.sleep()` before each crew's async kickoff.
* Scraping calls therefore block the event loop rather than running concurrently with one another.

    Flow->>Search: Search brand name (up to 15 results)

        Flow->>Search: Poll snapshot status
        Search-->>Flow: Current status
    end
    Flow->>Search: Fetch completed snapshot
    Search-->>Flow: Search records with organic results
    Flow->>Flow: Route links to LinkedIn, Instagram, YouTube, X, or web
    Flow->>Flow: Schedule five analysis tasks

        Flow->>Scraper: Submit LinkedIn URLs and dataset ID
        Scraper-->>Flow: Snapshot ID, then scraped post records
        Flow->>Flow: Select LinkedIn post fields
        Flow->>Crews: kickoff_async(linkedin_data, brand_name)
        Crews->>LLM: Analyze posts and write report
        LLM-->>Crews: Structured LinkedIn report
        Crews-->>Flow: Crew result
    and Instagram, if matching links exist
        Flow->>Scraper: Submit Instagram URLs and dataset ID
        Scraper-->>Flow: Snapshot ID, then scraped post records
        Flow->>Flow: Select Instagram fields, missing partnership flag becomes null
        Flow->>Crews: kickoff_async(instagram_data, brand_name)
        Crews->>LLM: Analyze posts and write report
        LLM-->>Crews: Structured Instagram report
        Crews-->>Flow: Crew result
    and YouTube, if matching links exist
        Flow->>Scraper: Submit YouTube URLs and dataset ID
        Scraper-->>Flow: Snapshot ID, then scraped video records
        Flow->>Flow: Skip error records and records without a usable URL
        opt Usable videos remain
            Flow->>Crews: kickoff_async(youtube_data, brand_name)
            Crews->>LLM: Analyze videos and write report
            LLM-->>Crews: Structured YouTube report
            Crews-->>Flow: Crew result
        end
    and X, if matching status links exist
        Flow->>Scraper: Submit X URLs and dataset ID
        Scraper-->>Flow: Snapshot ID, then scraped post records
        Flow->>Flow: Select X post fields
        Flow->>Crews: kickoff_async(x_data, brand_name)
        Crews->>LLM: Analyze posts and write report
        LLM-->>Crews: Structured X report
        Crews-->>Flow: Crew result
    and Web, if other matching links exist
        Flow->>Scraper: Submit web URLs and dataset ID
        Scraper-->>Flow: Snapshot ID, then scraped page records
        Flow->>Flow: Select URL and markdown
        Flow->>Crews: kickoff_async(web_data, brand_name)
        Crews->>LLM: Analyze pages and write report
        LLM-->>Crews: Structured web report
        Crews-->>Flow: Crew result
    end

    Flow->>Flow: Await all analysis tasks
    Flow->>Flow: Print reports for sources with results
    Flow-->>User: Process exits
