* Build an Agentic workflow that parses a travel query, fetches live flights and hotel data from Kayak, and summarizes the best options. 
* Tech stack: 
  * CrewAI for multi-agent orchestration 
  * Browserbase’s headless browser tool 
  * Ollama to locally serve DeepSeek-R1 
* Workflow: 
  * Parse the query (location, dates etc.) to create a Kayak search URL 
  * Visit the URL and extract top 5 flights 
  * For each hotel, find pricing and more info 
  * Summarize hotel info

# HotelFinder Pro Sequence Diagram

Flow of `app.py`. Streamlit reruns the script when widgets change; the LLM resource is reused across reruns.

```mermaid
sequenceDiagram
    actor User
    participant App as Streamlit app.py
    participant Env as Environment / .env
    participant Cache as load_llm resource cache
    participant Crew as CrewAI Crew / Planner
    participant Hotels as Hotels Agent
    participant Summary as Summarize Agent
    participant Ollama as Ollama localhost:11434
    participant Tools as kayak_hotels / browserbase

    User->>App: Open app or change a widget
    App->>App: Configure page and render heading
    App->>Env: load_dotenv()
    Env-->>App: Populate environment variables
    App-->>User: Render location, adults, dates, Search Hotels
    App->>Cache: load_llm()
    alt Cache miss
        Cache->>Cache: Create LLM client for ollama/llama3.2:3b
    else Cache hit
        Cache->>Cache: Reuse cached LLM client
    end
    Cache-->>App: LLM client
    App->>Hotels: Create agent with LLM and both tools
    App->>Cache: load_llm()
    Cache-->>App: Same LLM client
    App->>Summary: Create agent with LLM
    App->>App: Create search_task and search_booking_providers_task
    Note over Hotels,Summary: Both tasks belong to Hotels, Summary has no assigned task

    alt Search button not pressed
        App-->>User: Render About section
    else Search Hotels pressed on this rerun
        App->>Env: Read BROWSERBASE_API_KEY
        alt API key missing
            App-->>User: Show missing API key error
            Note over User,App: Error mentions sidebar, but current app has no sidebar key input
        else Check-out date is not after check-in date
            App-->>User: Show invalid dates error
        else Inputs pass validation
            App-->>User: Show searching spinner
            App->>App: Format hotel request with full ISO dates and adult count
            App->>Cache: load_llm()
            Cache-->>App: Same LLM client for planning_llm
            App->>Crew: Create crew with both agents and both tasks
            Note over App,Crew: planning=True, max_rpm=1, default sequential process
            Note over App,Crew: Crew construction is outside the try/except
            App->>Crew: kickoff(request, current_year)
            Crew->>Ollama: Generate execution plan using planning_llm
            Ollama-->>Crew: Task plans
            loop Each task in order: search, then booking providers
                Crew->>Hotels: Execute task with requested criteria and plan
                Note over Crew,Hotels: Booking task explicitly receives search_task output as context
                Hotels->>Ollama: Request next action or final answer
                Ollama-->>Hotels: Model response
                opt Agent chooses a tool, may repeat
                    Hotels->>Tools: Invoke selected tool
                    Tools-->>Hotels: Hotel or provider information
                    Hotels->>Ollama: Continue reasoning with tool result
                    Ollama-->>Hotels: Next action or task answer
                end
                Hotels-->>Crew: Task output
            end
            alt Kickoff and result display succeed
                Crew-->>App: Crew result
                App-->>User: Show success, Hotel Results, and result.raw
            else Exception during kickoff or result display
                Note over App,Crew: Failure can interrupt planning or any task
                App-->>User: Show error containing exception message
            end
            App-->>User: Stop searching spinner
        end
        App-->>User: Render About section
    end
```

* Tool calls are model-selected, not guaranteed.
* External behavior inside the imported tools is outside this diagram's scope.
* Exceptions during imports, agent initialization, or crew construction are not caught by the search handler.
