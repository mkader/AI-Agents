* Build an Agentic workflow that turns any URL into social media posts and auto-schedules them via Typefully. 
* Tech stack: 
  * Motia as the unified backend framework 
  * Firecrawl to scrape web content 
  * Ollama to locally serve Deepseek-R1 LLM 
* Workflow: 
  * User submits URL to scrape 
  * Firecrawl scrapes content and converts it to markdown 
  * Twitter and LinkedIn agents run in parallel to generate content 
  * Generated content gets scheduled via Typefully
 
* Workflow - Our workflow consists of 4 main steps:- API → Scrape → Generate → Schedule
  * API: Receives article URL via POST request
  * Scrape: Extracts content using Firecrawl in markdown format
  * Generate: Creates Twitter & LinkedIn content using Deepseek-R1
  * Schedule: Saves content as drafts in Typefully for review

* [Motia](https://www.motia.dev/), an open-source modern backend framework that brings together: Multi-agent orchestration, APIs, Event handling, and background jobs - everything under one unified system.
  * https://typefully.com/docs/api#tag/drafts/POST/v2/social-sets/{social_set_id}/drafts
  * Just like React streamlines frontend development, Motia simplifies the AI backend, where you only need one solution instead of a dozen tools.
  * Key features:
    * You can have Python, JS & TypeScript in the same workflow.
    * You can deploy from your laptop to prod in one click.
    * It has built-in observability & state management.
    * It provides automatic retries & fault tolerance.
    * It supports streaming response.

* Steps are the fundamental building blocks of Motia. They consist of two main components: 
  * The Config object: It instructs Motia on how to interact with a step. 
  * The handler function: It defines the main logic of a step. 
  <img width="300" height="350" alt="image" src="https://github.com/user-attachments/assets/ae198c37-4139-435c-9333-1e36ea36dfe7" />

```mermaid
sequenceDiagram
    autonumber
    actor Client as Browser / Postman / Swagger
    participant API as ContentGenerationAPI
    participant Events as Motia events
    participant Scraper as ScrapeArticle
    participant Firecrawl
    participant LinkedIn as LinkedinGenerate
    participant Twitter as TwitterGenerate
    participant OpenAI as Selected AI provider (OpenAI / Azure OpenAI / Ollama)
    participant LinkedInDraft as ScheduleLinkedin
    participant TwitterDraft as ScheduleTwitter
    participant Typefully
    actor User as User reviewing drafts

    Client->>API: POST /generate-content (JSON with url)
    API->>API: Validate HTTP/HTTPS URL with Pydantic
    alt Invalid request body
        API-->>Client: 400 (error)
    else Valid request body
        API->>Events: Emit scrape-article (requestId, url, timestamp)
        API-->>Client: 200 (requestId, url, status: processing)
        Note over API,Events: Downstream work may start before the HTTP response arrives.
        Events-->>Scraper: Deliver scrape-article
        Scraper->>Firecrawl: Scrape article URL
        Firecrawl-->>Scraper: Markdown and metadata
        Scraper->>Scraper: Require non-empty markdown and extract title
        Scraper->>Events: Emit generate-content (requestId, url, title, content, timestamp)

        par LinkedIn branch
            Events-->>LinkedIn: Deliver generate-content
            LinkedIn->>LinkedIn: Load LinkedIn prompt and insert title and content
            LinkedIn->>OpenAI: Generate JSON LinkedIn post
            OpenAI-->>LinkedIn: JSON containing post
            LinkedIn->>LinkedIn: Parse JSON response
            LinkedIn->>Events: Emit linkedin-schedule (requestId, url, title, content)
            Events-->>LinkedInDraft: Deliver linkedin-schedule
            LinkedInDraft->>Typefully: POST /v2/social-sets/{socialSetId}/drafts (platforms.linkedin.posts)
            Typefully-->>LinkedInDraft: Draft creation response
            LinkedInDraft->>LinkedInDraft: Log success
        and Twitter branch
            Events-->>Twitter: Deliver generate-content
            Twitter->>Twitter: Load Twitter prompt and insert title and content
            Twitter->>OpenAI: Generate JSON Twitter thread
            OpenAI-->>Twitter: JSON containing thread
            Twitter->>Twitter: Parse JSON response
            Twitter->>Events: Emit twitter-schedule (requestId, url, title, content)
            Events-->>TwitterDraft: Deliver twitter-schedule
            TwitterDraft->>TwitterDraft: Map each tweet to a text entry in thread order
            TwitterDraft->>Typefully: POST /v2/social-sets/{socialSetId}/drafts (platforms.x.posts)
            Typefully-->>TwitterDraft: Draft creation response
            TwitterDraft->>TwitterDraft: Log success
        end

        Note over Client,Typefully: No completion callback or final result is returned to the original HTTP request.
        User->>Typefully: Review drafts and publish manually
    end
```
