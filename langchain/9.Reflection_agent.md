```
'''
Reflection
In the context of LLM agent building, reflection refers to the process of prompting an LLM to observe its past steps 
(along with potential observations from tools/the environment) to assess the quality of the chosen actions. 
This is then used downstream for things like re-planning, search, or evaluation.
'''
```

```
import asyncio
import os
from dotenv import load_dotenv
from langchain_core.messages import AIMessage, BaseMessage, HumanMessage
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_fireworks import ChatFireworks
from langchain_openai import AzureChatOpenAI

load_dotenv()

'''
Generate - create a "5 paragraph essay" generator. First, create the generator:
'''

prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "You are an essay assistant tasked with writing excellent 5-paragraph essays."
            " Generate the best essay possible for the user's request."
            " If the user provides critique, respond with a revised version of your previous attempts.",
        ),
        MessagesPlaceholder(variable_name="messages"),
    ]
)
#llm = ChatFireworks( model="accounts/fireworks/models/mixtral-8x7b-instruct", max_tokens=32768)

llm = AzureChatOpenAI(
    azure_deployment=os.environ["AZURE_OPENAI_DEPLOYMENT_NAME_LLM"],
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT_LLM"],
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    api_version="2025-03-01-preview"
)

generate = prompt | llm
essay = ""
request = HumanMessage(
    content="Write an essay on why the little prince is relevant in modern childhood"
)

for chunk in generate.stream({"messages": [request]}):
    print(chunk.content, end="")
    essay += chunk.content

'''    
Reflect
'''
reflection_prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "You are a teacher grading an essay submission. Generate critique and recommendations for the user's submission."
            " Provide detailed recommendations, including requests for length, depth, style, etc.",
        ),
        MessagesPlaceholder(variable_name="messages"),
    ]
)
reflect = reflection_prompt | llm
reflection = ""

for chunk in reflect.stream({"messages": [request, HumanMessage(content=essay)]}):
    print(chunk.content, end="")
    reflection += chunk.content

'''
Repeat -repeat in a loop for a fixed number of steps, or use an LLM (or other check) to decide when the finished product is good enough.
'''

for chunk in generate.stream(
    {"messages": [request, AIMessage(content=essay), HumanMessage(content=reflection)]}
):
    print(chunk.content, end="")

'''
Define graph
'''

from typing import Annotated, List, Sequence
from langgraph.graph import END, StateGraph, START
from langgraph.graph.message import add_messages
from langgraph.checkpoint.memory import InMemorySaver
from typing_extensions import TypedDict

class State(TypedDict):
    messages: Annotated[list, add_messages]

async def generation_node(state: State) -> State:
    return {"messages": [await generate.ainvoke(state["messages"])]}

async def reflection_node(state: State) -> State:
    # Other messages we need to adjust
    cls_map = {"ai": HumanMessage, "human": AIMessage}
    # First message is the original user request. We hold it the same for all nodes
    translated = [state["messages"][0]] + [
        cls_map[msg.type](content=msg.content) for msg in state["messages"][1:]
    ]
    res = await reflect.ainvoke(translated)
    # We treat the output of this as human feedback for the generator
    return {"messages": [HumanMessage(content=res.content)]}

builder = StateGraph(State)
builder.add_node("generate", generation_node)
builder.add_node("reflect", reflection_node)
builder.add_edge(START, "generate")

def should_continue(state: State):
    if len(state["messages"]) > 6:
        # End after 3 iterations
        return END
    return "reflect"

builder.add_conditional_edges("generate", should_continue)
builder.add_edge("reflect", "generate")
memory = InMemorySaver()
graph = builder.compile(checkpointer=memory)
config = {"configurable": {"thread_id": "1"}}

async def run_graph():
    async for event in graph.astream(
        {
            "messages": [
                HumanMessage(
                    content="Generate an essay on the topicality of The Little Prince and its message in modern life"
                )
            ],
        },
        config,
    ):
        print(event)
        print("---")


asyncio.run(run_graph())

state = graph.get_state(config)
ChatPromptTemplate.from_messages(state.values["messages"]).pretty_print()

```

### Code Explanation
* essay-writing workflow: a direct generate–critique–revise sequence, followed by a LangGraph version that runs its own workflow.

* Builds a generation prompt that asks for a five-paragraph essay and includes a placeholder for conversation messages.

* Generate an essay directly (generate = prompt | llm)
  * The first request asks for an essay about The Little Prince and modern childhood.
  * The generate chain combines the prompt with the model.
  * Its .stream() call prints the essay as it arrives in chunks, while also appending those chunks to essay so the full response is available afterward.

* Critique the essay, then revise it (reflection_prompt = ChatPromptTemplate.from_messages()
  * builds a separate prompt instructing the model to act as a teacher and critique an essay.
  * It sends the original request and the generated essay to that chain, streams the critique to the console, and collects it in reflection.
 
* Then it calls the generation chain again with the original request, the first essay, and the critique.
  * This asks the model to produce a revised version. That revision is printed, but not saved to a variable.

* Define the graph-based version (class State(TypedDict):)
  * After the direct example, the file defines a LangGraph workflow:
    * State holds the conversation’s messages; add_messages makes node updates append to the message history.
    * generation_node sends that history to the generation chain and adds the model’s response.
    * reflection_node changes message roles before asking for critique: prior AI messages become human messages and prior human messages become AI messages, while the initial request stays unchanged. The critique is then added as a human message so the generator can use it as feedback.

* Run the graph in a loop
  * The graph starts at generate, then uses should_continue to choose between ending and moving to reflect.
  * Reflection loops back to generation.
  * InMemorySaver stores graph state in memory, and thread_id identifies the conversation.
  * Finally, asyncio.run(run_graph()) starts the async graph run; each event and a separator are printed.
  
* The graph starts with a new request of its own. It does not continue from the essay and critique created in the earlier direct example.
  * After it finishes, the script retrieves the saved graph state and prints a prompt representation of its messages. See the graph’s initial request and the final state display.

One detail to note: the comment says the graph ends after three iterations, but should_continue checks whether the message count is greater than 6. Since the initial request is already one message and each generation and reflection adds another, that condition results in four generation passes and three reflection passes before stopping—not three generation passes.
