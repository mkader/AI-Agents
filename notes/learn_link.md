
1. [GenAI Agents](https://github.com/NirDiamant/GenAI_Agents)
One of the most hands on repos out there. You will learn memory, planning, execution loops, tool calling and real agent behaviors. Great for building intuition. 

2. [Agents Engineering Course](https://github.com/ed-donner/agents)
A mini course focused entirely on how agents actually work in production environments. Covers design patterns, planning, routing, and multi agent setups.

4. [AI Agents for Beginners (Microsoft)](https://github.com/microsoft/ai-agents-for-beginners)
A complete beginner friendly curriculum with 11 practical lessons. You build agents step by step without getting overwhelmed.

5. [Awesome AI Agents](https://github.com/e2b-dev/awesome-ai-agents)
A curated directory of frameworks, libraries, patterns, and papers across the agent ecosystem. Great when you want to explore the broader landscape.

6. [AI Agents Masterclass (Code + Lessons)](https://github.com/coleam00/ai-agents-masterclass)
Companion repo to one of the best masterclasses on agents. Clear examples, reusable templates, and real architectures that are easy to adapt.

Build AI agents with 6 learning resources and GitHub repositories, arranged in a practical order: Foundations → Design Patterns → Build → Examples → Security → Evaluation

Basic Python knowledge will help with the coding sections.

1. [FOUNDATIONS — Hugging Face AI Agents Course](https://huggingface.co/learn/agents-course/en/unit1/introduction)
Learn how agents combine models, tools and actions. Start with Unit 1.

2️. [DESIGN PATTERNS — Microsoft AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners)
Explore tool use, planning, agentic RAG, memory and multi-agent systems through lessons and Python examples.

3. [BUILD — Google Agent Development Kit (ADK)](https://adk.dev/)
Follow the quickstart, connect tools, and learn about sessions and state.
[Python SDK](https://github.com/google/adk-python)
[PRACTICAL EXAMPLES — Google ADK Recipes. Explore examples covering session memory, authentication, guardrails and retrieval.](https://github.com/google/adk-recipes)

3. SECURITY — NVIDIA OpenShell
Understand sandboxing, access policies, and how network requests and credentials are managed outside the agent.
[Architecture](https://docs.nvidia.com/openshell/about/architecture)
[GitHub](https://github.com/NVIDIA/OpenShell)

4. EVALUATION — NVIDIA NeMo Agent Toolkit
Learn how to evaluate agent behaviour, measure reliability and explore evaluation workflows.
[Guide](https://docs.nvidia.com/nemo/agent-toolkit/latest/improve-workflows/evaluate.html)
[GitHub](https://github.com/NVIDIA/NeMo-Agent-Toolkit)
